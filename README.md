# Kamil Ciesielski

Software developer based in Poland. Working mainly with **PHP, WordPress, WooCommerce, Elixir and Phoenix**, building everything from custom integrations and backend services to mobile applications and AI-powered tools.

I focus on solving real problems, improving existing systems and building products from the ground up.

Most of my professional work lives in private repositories or production environments. What you'll find here is a mix of personal projects, experiments and things I'm building along the way.

### Projects

- [**WooSense**](https://woosense.pl/en/) — a mobile companion for WooCommerce store owners. Orders, sales statistics, push notifications and AI-powered insights, all accessible from a smartphone.
- [**Żłobek Blisko**](https://zlobekblisko.pl/) — a platform helping parents discover and compare nurseries in Poland.

### What I actually do

Custom WordPress plugins, WooCommerce development, backend architecture, API integrations and automation.

Beyond WordPress, I work with **Elixir/Phoenix**, building backend services, processing pipelines and integrations between different systems.

I'm also interested in AI engineering — particularly LLMs, RAG, semantic search, embeddings and bringing AI into real applications rather than just building demos.
